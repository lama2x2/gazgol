# 9.1 BFS, DFS и топологическая сортировка

## Как хранить граф:
| Представление | Память | Проверить ребро u–v | Перебрать соседей u | Когда |
|---|---|---|---|---|
| список смежности `{u: [v, …]}` | O(V + E) | O(deg u) | O(deg u) | почти всегда, разреженные графы |
| матрица смежности `V × V` | O(V²) | O(1) | O(V) | плотные графы, маленькие V |
| список рёбер `[(u, v, w), …]` | O(E) | O(E) | O(E) | Краскал, Беллман — Форд |
| сетка (grid) | — | соседи `(r±1, c)`, `(r, c±1)` | 4 соседа | острова, лабиринты |

Яндекс любит графы, потому что на них легко ложатся реальные задачи: зависимости сборки, маршруты, связи пользователей, микросервисы.

## BFS — обход в ширину:
Очередь; посещаем вершины слоями по расстоянию от старта. Даёт **кратчайший путь по числу рёбер** в невзвешенном графе. O(V + E).
```python
from collections import deque

def bfs(graph, start):
    dist = {start: 0}
    q = deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:          # отмечаем при добавлении, а не при извлечении
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

## DFS — обход в глубину:
Стек (или рекурсия); идём вглубь до упора, затем откатываемся. Для компонент связности, поиска циклов, топологической сортировки, «есть ли путь». O(V + E). Рекурсивный DFS в Python упирается в лимит рекурсии (1000) на длинных цепочках — на собесе пиши итеративный или скажи о `sys.setrecursionlimit`.

## Топологическая сортировка:
Порядок вершин ориентированного графа без циклов (DAG), в котором каждое ребро `u → v` идёт слева направо: сначала зависимость, потом зависящий. **Алгоритм Кана:**
1. посчитай входящие степени
2. положи в очередь все вершины со степенью 0
3. достаёшь вершину → в ответ; у её соседей уменьшаешь степень; ставшие нулевыми — в очередь
4. если в ответе меньше V вершин — в графе **цикл**

Применения: порядок миграций, сборка зависимостей пакетов, планирование задач с зависимостями (DAG в Airflow), порядок вычисления ячеек в таблице.

::: solve Число островов (LeetCode 200)
*«Сетка из '1' и '0'. Каждая непосещённая единица — новый остров; запускаю от неё обход и закрашиваю весь остров. Каждая клетка посещается один раз — O(R·C). Пишу BFS, а не рекурсивный DFS: остров 1000 × 1000 — миллион уровней рекурсии».*
```python
def num_islands(grid):
    R, C = len(grid), len(grid[0]) if grid else 0
    seen, count = set(), 0
    for r in range(R):
        for c in range(C):
            if grid[r][c] == "1" and (r, c) not in seen:
                count += 1
                seen.add((r, c))
                q = deque([(r, c)])
                while q:
                    y, x = q.popleft()
                    for ny, nx in ((y + 1, x), (y - 1, x), (y, x + 1), (y, x - 1)):
                        if 0 <= ny < R and 0 <= nx < C and grid[ny][nx] == "1" and (ny, nx) not in seen:
                            seen.add((ny, nx))
                            q.append((ny, nx))
    return count
```
:::

::: quiz output q91-2
Что выведет программа?
```python
from collections import deque

def kahn(n, edges):
    g = {i: [] for i in range(n)}
    indeg = [0] * n
    for u, v in edges:
        g[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None

print(kahn(4, [(0, 1), (0, 2), (1, 3), (2, 3)]))
print(kahn(3, [(0, 1), (1, 2), (2, 0)]))
```
--- answer
[0, 1, 2, 3]
None
--- why
В первом графе 3 зависит от 1 и 2, а те — от 0. Во втором — цикл 0→1→2→0: ни у одной вершины нет нулевой входящей степени, очередь пуста с самого начала, и алгоритм сообщает о цикле.

! Петля `(a, a)` — цикл. Курсы без зависимостей тоже входят в n.
* `topo_order` — порядок выполнения задач с зависимостями; среди готовых к выполнению всегда бери **наименьшую** по номеру; цикл — `None` {test_topo_order}
+ Кан, но вместо очереди — куча `heapq`: так на каждом шаге извлекается наименьшая вершина с нулевой степенью. O((V + E) log V).
! С обычной очередью порядок тоже будет корректным, но не тем, что требует условие. Детерминированный порядок — частое уточнение на собесе.
* `word_ladder ★` — минимальное число слов в цепочке от `begin` до `end`, где соседние слова отличаются одной буквой и все промежуточные — из словаря; нет цепочки — 0 (LeetCode 127) {test_word_ladder}
+ BFS по словам. Соседей генерируй через «шаблоны»: для `hot` — `*ot`, `h*t`, `ho*`; заранее построй словарь «шаблон → слова». Тогда соседи слова находятся за O(L), а не перебором всего словаря.
! Попарное сравнение всех слов — O(N² · L), тест на 5000 слов не уложится. `end` должен быть в словаре, иначе 0. Длина цепочки считается в словах, включая `begin` и `end`.

## Вопросы с собеседования по уроку:
::: quiz open q91-3 собес
Чем BFS отличается от DFS? Когда что использовать?
--- answer
Оба обходят все достижимые вершины за O(V + E). BFS использует очередь и обходит по слоям — по возрастанию расстояния от старта в рёбрах. Поэтому он находит кратчайший путь в невзвешенном графе (лабиринт, «через сколько рукопожатий», минимум ходов) и обходит дерево по уровням. Память — до ширины слоя. DFS использует стек (явный или рекурсию) и уходит вглубь. Удобен для компонент связности, поиска циклов (цвета белый/серый/чёрный в ориентированном графе), топологической сортировки (вершины в порядке выхода), перебора путей и backtracking. Память — до глубины, но рекурсия в Python ограничена (~1000), поэтому для больших графов — итеративный стек. Если нужен кратчайший путь с весами — Дейкстра (неотрицательные веса), а с весами 0 и 1 — BFS с двусторонней очередью (0-1 BFS).
--- points
- очередь против стека, слои против глубины
- BFS: кратчайший путь без весов, уровни
- DFS: компоненты, циклы, топосорт, перебор
- одинаковая сложность O(V + E), разная память
- рекурсия в Python и веса → Дейкстра
:::
