# 8.1 Стек, очередь и монотонный стек

## Стек — LIFO:
В Python стек — обычный `list`: `append` и `pop()` с конца за O(1). **Сигналы:** вложенность (скобки, теги, выражения), «отменить последнее», обработка «в обратном порядке», «ближайший больший / меньший элемент», обход дерева без рекурсии.

## Очередь — FIFO:
`collections.deque`: `append` и `popleft()` за O(1). `list.pop(0)` — O(n), на собесе это заметят. **Сигналы:** обработка «по мере поступления», BFS, скользящее окно с максимумом, буфер последних N событий (`deque(maxlen=N)`).

::: solve Скобочная последовательность (LeetCode 20) — разминка в половине собесов
```python
def is_valid(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack                 # незакрытые скобки — тоже ошибка
```
*«Проверка: `"([)]"` — на `)` вершина стека `[`, не совпало, False. Граничные: пустая строка — True; `"(("` — стек не пуст — False; `")"` — стек пуст при закрытии — False».*
:::

## Монотонный стек:
Стек, в котором элементы всегда идут по возрастанию (или убыванию). Когда приходит новый элемент, мы выталкиваем всё, что он «побеждает», — и для вытолкнутых он и есть ответ «ближайший справа больший». Каждый элемент кладётся и вынимается один раз — O(n) вместо O(n²).
```python
def next_greater(a):
    res = [-1] * len(a)
    stack = []                        # индексы, значения по убыванию
    for i, x in enumerate(a):
        while stack and a[stack[-1]] < x:
            res[stack.pop()] = x      # x — ближайший справа больший для вершины
        stack.append(i)
    return res
```

```python
def next_greater(a):

    stack = []

print(next_greater([2, 1, 2, 4, 3]))
print(next_greater([5, 4, 3]))
```
--- answer
[4, 2, 4, -1, -1]
[-1, -1, -1]
--- why
Для первой двойки ближайшее большее справа — 4: равная двойка её не выталкивает (строгое `<`). Единицу вытолкнула вторая двойка. В убывающем массиве никто никого не выталкивает. Если поменять `<` на `<=`, равные элементы будут считаться «большими» — частый вопрос уточнения к условию.

## Вопросы с собеседования по уроку:
::: quiz open q81-3
Как реализовать очередь на двух стеках? Какая сложность операций?
--- answer
Два стека: `inbox` для добавления и `outbox` для извлечения. `push(x)` — `inbox.append(x)`, O(1). `pop()` — если `outbox` пуст, переложить все элементы из `inbox` в `outbox` (порядок разворачивается, и самый старый оказывается наверху), затем `outbox.pop()`. Каждый элемент перекладывается ровно один раз за всю жизнь, поэтому амортизированная сложность `pop` — O(1), хотя отдельная операция может стоить O(n). Это классический пример амортизированного анализа. В Python на практике используют `collections.deque`, а для потоков — `queue.Queue`.
--- points
- inbox и outbox
- перекладывание, только когда outbox пуст
- разворот порядка даёт FIFO
- амортизированное O(1) и объяснение
- на практике deque / queue.Queue
:::
