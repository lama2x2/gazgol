# 7.3 Скользящее окно

## Когда узнавать паттерн:
**Сигналы:** «непрерывный подотрезок / подстрока», «самый длинный / короткий / сколько подотрезков, где выполняется условие», «не больше k различных», «без повторов», «сумма окна длины k». Окно `[left, right]` двигается вправо: правая граница добавляет элемент, левая убирает. Каждый элемент входит и выходит из окна по одному разу — O(n).

**Условие применимости:** если окно «хорошее», то и любое вложенное в него — тоже хорошее (или наоборот). Тогда при нарушении достаточно сдвигать левую границу. С отрицательными числами для сумм это свойство ломается — там нужны префиксные суммы (урок 7.1).

## Шаблон окна переменной длины:
```python
def longest_good(a):
    counts = {}              # состояние окна
    left = best = 0
    for right, x in enumerate(a):
        counts[x] = counts.get(x, 0) + 1          # 1. добавить правый
        while not good(counts):                   # 2. пока окно плохое —
            y = a[left]                           #    убрать левый
            counts[y] -= 1
            if counts[y] == 0:
                del counts[y]
            left += 1
        best = max(best, right - left + 1)        # 3. окно хорошее — обновить ответ
    return best
```
Внутренний `while` не делает решение O(n²): `left` за всё время сдвигается не больше n раз.

::: solve Самая длинная подстрока без повторов (LeetCode 3)
Окно хорошее, если в нём нет повторов. Вместо счётчиков удобно хранить **последний индекс** каждого символа и прыгать левой границей сразу за предыдущее вхождение:
```python
def longest_unique(s):
    last = {}
    left = best = 0
    for right, ch in enumerate(s):
        if last.get(ch, -1) >= left:     # повтор внутри окна
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best
```
Проверка `>= left` важна: символ мог встречаться раньше, но уже **вне** окна — тогда левую границу трогать нельзя («abba»: на второй `a` прошлое вхождение левее окна).
:::

::: quiz choice q73-1 собес
Задача: «Найти количество подотрезков, в которых все значения различны» (вторая задача Яндекса из официального разбора). Как посчитать за O(n)?
- [ ] перебрать все подотрезки и проверить каждый через `set` — O(n²)
- [x] для каждой правой границы найти самую левую границу, при которой окно без повторов; тогда подходящих отрезков, заканчивающихся в `right`, ровно `right - left + 1` — сложить
- [ ] отсортировать массив и посчитать уникальные
- [ ] префиксные суммы
--- why
Если окно `[left, right]` без повторов, то и все его суффиксы `[left', right]` при `left' ≥ left` — тоже. Значит, при фиксированном `right` хорошие отрезки — это ровно `right - left + 1` штук. Это частый приём: «самый длинный» превращается в «сколько всего», если суммировать длины окон.
:::

::: quiz output q73-2
Что выведет программа?
```python
def max_window_sum(a, k):
    s = sum(a[:k])
    best = s
    for i in range(k, len(a)):
        s += a[i] - a[i - k]
        best = max(best, s)
    return best

print(max_window_sum([1, 4, 2, 10, 2, 3, 1, 0, 20], 4))
print(max_window_sum([-1, -2, -3], 2))
```
--- answer
24
-3
--- why
Окно фиксированной длины: на каждом шаге прибавляем вошедший элемент и вычитаем вышедший, без пересчёта суммы — O(n). Лучшее окно — [3, 1, 0, 20] = 24. Начальное значение `best` — сумма первого окна, а не 0: иначе для отрицательных чисел вернётся неверный 0.

+ `need = Counter(t)` и счётчик `missing = len(t)`. Двигай правую границу: если символ нужен (`need[ch] > 0`), уменьши `missing`; уменьши `need[ch]` всегда. Когда `missing == 0`, сдвигай левую границу, пока окно остаётся полным, запоминая лучшее, затем выйди из «полного» состояния.
! Сравнивать `Counter` окна с `Counter(t)` на каждом шаге — O(n · |алфавит|): терпимо, но на собесе спросят O(n). Кратность важна: для `t = "aa"` окно должно содержать две `a`.

## Вопросы с собеседования по уроку:
::: quiz open q73-3
Как понять, что задачу можно решить скользящим окном, а когда окно не работает?
--- answer
Признаки: речь о непрерывном подотрезке или подстроке и об экстремуме (самый длинный, самый короткий) или количестве таких отрезков, а условие «монотонно» по включению: если окно удовлетворяет условию, то и любое вложенное (для «самый длинный») тоже удовлетворяет, либо наоборот (для «самый короткий»). Тогда при нарушении достаточно сдвигать левую границу, и каждый элемент войдёт и выйдет из окна один раз — O(n). Окно не работает, когда монотонности нет: сумма подотрезка с отрицательными числами (расширение может уменьшить сумму) — там префиксные суммы со словарём; подпоследовательности (не непрерывные) — там динамика; условия на весь массив сразу. Для окна фиксированной длины достаточно обновлять агрегат при сдвиге; если агрегат — максимум окна, нужна монотонная очередь (deque).
--- points
- непрерывный подотрезок и экстремум или подсчёт
- монотонность условия по включению
- амортизированное O(n): каждый элемент входит и выходит раз
- когда не работает: отрицательные суммы, подпоследовательности
- фиксированное окно и максимум окна через deque
:::
