# Python: подготовка к собеседованию и лайвкодингу

Курс в формате «лист за листом» с автопроверкой домашек и тренажёрами «подумать»: «Что выведет?», «Найди баг», «Выбери», «Вопрос с собеса», «Спроектируй», «Код-ревью». Построен по реальным форматам собеседований Яндекса, Авито, Ozon, Т-Банка, Kaspersky, VK и рубрикам Google и Meta. Источники перечислены в уроке 1.1.

| Часть | Модули | Конспект |
|---|---|---|
| 1. Язык (платформенная секция) | 1–6: как устроен собес, объекты и коллекции изнутри, замыкания и декораторы, генераторы, контекстные менеджеры, ООП и дескрипторы, память и GIL, потоки и asyncio, типизация и тесты | `py1.html` |
| 2. Алгоритмы (лайвкод) | 7–10: хеши и префиксные суммы, два указателя, окно, бинарный поиск, стек, списки, деревья, кучи и интервалы, графы, перебор, динамика, жадные и битовые | `py2.html` |
| 3. Бэкенд | 11–14: задачи «как в продакшене», бизнес-логика, код-ревью, SQL, индексы и транзакции, HTTP и REST, WSGI/ASGI, Django и FastAPI, очереди и надёжность, system design и поведенческое | `py3.html` |

Нужен Python 3.12+ и pytest (`python3 -m pip install pytest`).

## Решать прямо в конспекте

```bash
python3 pycourse/lyceum.py
```

Открой http://localhost:4002 (часть 1), `/part2`, `/part3`. У каждой домашки есть кнопка «Решать здесь» — редактор урока: <kbd>⌘/Ctrl+Enter</kbd> проверяет, <kbd>⌘/Ctrl+S</kbd> сохраняет. Код пишется в тот же файл, что открывается в IDE.

## Или в редакторе кода

1. Прочитай урок в конспекте.
2. Открой `lessonNN/tasks.py`: условия в docstring, заготовки с `raise NotImplementedError`. В уроке 6.1 тесты пишешь ты — файл `student_tests.py`, а проверка запускает их на «мутантах» `cart.py`. В уроке 11.3 код уже написан, но с ошибками — их нужно найти. В уроке 12.1 ответы — SQL-запросы.
3. Проверяй:

```bash
python3 pycourse/check.py          # все уроки
python3 pycourse/check.py 31       # только урок 3.1, с ошибками
```

Тестовые файлы (`test_*.py`) не трогай: это проверяющая система. Задачи со ★ — уровень сильного лайвкода. Решай как на собесе: проговори идею и сложность, напиши, проверь в уме — и только потом запускай проверку.
