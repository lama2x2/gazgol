# Курс Go: от основ до Middle backend

Конспекты в формате «лист за листом», домашки с автопроверкой (как в Яндекс Лицее) и тренажёры «подумать»: «Что выведет?», «Найди баг», «Выбери», «Вопрос с собеса», «Спроектируй», «Код-ревью».

| Часть | Модули | Конспект |
|---|---|---|
| 1. Основы | 1–6: типы, условия, циклы, функции, указатели, ООП, горутины | `konspekt.html` |
| 2. Junior backend | 7–12: Go изнутри, ошибки и тесты, HTTP/REST, SQL, context и паттерны, Docker/CI | `part2.html` |
| 3. Middle backend | 13–18: runtime и GC, конкурентность глубже, PostgreSQL изнутри, архитектура и observability, распределённые системы, system design | `part3.html` |

## Решать прямо в конспекте

```bash
go run ./course/cmd/lyceum
```

Открой http://localhost:4001 (часть 1), `/part2`, `/part3`. У каждой домашки есть кнопка «Решать здесь» — редактор урока: <kbd>⌘/Ctrl+Enter</kbd> проверяет, <kbd>⌘/Ctrl+S</kbd> сохраняет. Код пишется в тот же файл и форматируется как gofmt. У каждой задачи есть пояснение «Как решать».

## Или в редакторе кода

1. Прочитай урок в конспекте.
2. Открой `lessonNN/tasks.go`: там условия и заготовки с `// TODO`. В уроке 8.2 тесты пишешь ты — файл `student_test.go`.
3. Проверяй:

```bash
./course/check.sh          # все уроки
./course/check.sh 101      # только урок 10.1
./course/check.sh 101 -v   # + что именно не так
```

Тестовые файлы (`tasks_test.go`, `zz_meta_test.go`) не трогай: это проверяющая система. Уроки с конкурентностью проверяются с `-race`. Задачи со ★ — повышенной сложности.

## Инструменты

- `go run ./course/cmd/sqlrun "SELECT * FROM ads"` — песочница с учебной базой для урока 10.1
- `python3 course/tools/build.py --verify` — собрать конспекты частей 2–3 из `content/` и проверить ответы «Что выведет?» реальным запуском кода
